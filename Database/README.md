# Database

A SzervizPont SQLite relációs adatbázist használ.

- `schema.sql`: a négy fő tábla és a kapcsolatok SQL szerkezete.
- `SzervizPont_adatbazis_diagram.png`: az adatbázis kapcsolati ábrája.
- `szervizpont.db`: az alkalmazás első indításakor automatikusan jön létre ebben a mappában.

A futás közben létrejövő `.db` fájl nincs verziókezelés alatt, így a tesztfelhasználók adatai nem kerülnek fel a GitHubra.
